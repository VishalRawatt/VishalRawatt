# 👨‍💻 About Me

I am a **Cybersecurity professional and Master's student** focused on **Offensive Security, Defensive Security, SOC Operations, Security Automation, and Security Engineering**.

I enjoy understanding systems from both sides of the security boundary — **how attackers discover and exploit weaknesses, and how defenders detect, investigate, contain, and harden against them.**

My software-development background allows me to approach security from both the **attacker and builder perspective**, helping me create practical security tools, automation workflows, web applications, and infrastructure.

- 🔴 **Offensive Security** — Web & Network Pentesting, Vulnerability Assessment, Reconnaissance & Exploitation
- 🔵 **Defensive Security** — SOC Operations, SIEM, Threat Detection, Threat Hunting & Incident Response
- 🟣 **Security Engineering** — Automation, SOAR, Cloud Security, Infrastructure & Detection Engineering
- ⚙️ **Security Automation** — Python, n8n, Splunk, SOAR workflows and automated response
- 🌐 **Development** — Python, JavaScript/TypeScript, React, Node.js, Express & MongoDB
- ☁️ **Infrastructure** — Linux, Docker, AWS, Networking & Virtualization
- 📚 **Research** — Cybersecurity research, security projects and technical experimentation

> **Build. Break. Investigate. Automate. Defend.**
